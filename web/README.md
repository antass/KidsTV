# World Zoom (web)

The browser version of World Zoom, published as a claude.ai artifact.
`world-zoom.html` is the page body (the artifact host adds the `<html>` shell);
it loads `world.json` (copy of `../WorldZoom/Data/world.json`) and, when present,
`wiki.json` (from `tools/fetch_wiki.py`) from the same folder.

Screens: Zoom Out, Spin the Globe, Find It!, What Is It?, Stack It, Cheat Sheet.
