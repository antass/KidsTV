# Charlie's Drum Room

A drum practice web app for Charlie. It's a single file (`index.html`) with no
build step and nothing to install. Open it in any browser.

Live version: https://claude.ai/artifact/3enyAWtXePEBQ5HtRe3BoB

## What's in it

- **Metronome**: 40–220 BPM, tap tempo, 2/4 · 3/4 · 4/4 · 6/8, and quarter,
  8th, triplet or 16th clicks.
- **Beats**: six play-along grooves (Level 1–3) plus "Charlie's Beat", which
  he builds himself. A 16-step grid and a top-down drum kit light up as each
  drum plays. Modes: drums + click, drums only, or click only (he plays it).
- **Rudiments**: singles, doubles, paradiddles, triplets, paradiddle-diddles
  and double paradiddles. R/L letters light up in time, and stick tips show on
  the snare. With headphones, the right hand plays in the right ear and the
  left hand in the left.
- **Count-in** and **speed ladder** (the tempo goes up every few bars) in
  every mode.
- **Practice clock and log**: daily goal ring, day streak, last 7 days, and a
  list of saved sessions.

## Where practice sessions are saved

- On the claude.ai link, sessions are saved with the artifact, so they show up
  on any device signed in to the same account.
- Opened from this file, sessions are saved in that browser only.

All sounds are synthesized in the browser with the Web Audio API, so there are
no audio files.
